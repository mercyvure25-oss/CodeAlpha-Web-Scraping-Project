Web Scraping Project using python 

CodeAlpha Internship Project

This project was successfully completed as part of my internship at CodeAlpha. The objective of this project is to perform web scraping using Python and generate a structured dataset from website data.


---

Project Description

Web scraping is a technique used to extract information from websites automatically. In this project, Python libraries such as BeautifulSoup, Requests, and Pandas were used to collect data from a webpage and store it in CSV format for further analysis.


---

Technologies Used

Python

BeautifulSoup

Requests

Pandas



---

Project Workflow

1. Installation of Required Libraries

Installed the necessary Python libraries required for web scraping and data handling.

2. Website Connection

Established a connection with the target website using the Requests library.

3. Data Extraction

Analyzed the HTML structure of the webpage and extracted quotes data using BeautifulSoup.

4. Dataset Creation

Organized the extracted data into a structured format using Pandas DataFrame.

5. CSV File Generation

Stored the final dataset successfully in CSV format.
